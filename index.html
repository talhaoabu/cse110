    FAQ

    প্রশ্ন আছে?

    সবচেয়ে বেশি যে প্রশ্নগুলো আসে।

    Paid resource এ কীভাবে access পাবো?

    Payment করার পর paid group এ add করে দিবো। তারপর Drive এর file এ access request দিলে আমি approve করে দিবো। সব resource আর class recording Google Docs এ সাজানো থাকে।

    কোন resource গুলো সবার জন্য free?

    Assignment 01–04, তাদের solution আর visualizer website সবার জন্য free। Tracing, error finding আর আগের mid question এর কিছু file ও free। Paid file গুলোর পাশে Paid লেখা থাকে।

    Mentorship আর Resources Only এর মধ্যে পার্থক্য কী?

    Mentorship এ class, Google Meet guidance আর সব past resource পাবে। Resources Only (৳3,500) এ পুরো semester এর past question আর practice sheet পাবে, কিন্তু class support থাকবে না।

    একদম জিরো থেকে শুরু করলে পারবো?

    হ্যাঁ। Variable আর data type থেকে শুরু করে ধাপে ধাপে exam level এর problem পর্যন্ত যাওয়া হয়। Learning Path ধরে আগালেই হবে।

    কোথাও আটকে গেলে কী করবো?

    আগে থেকে জানাও, Google Meet এ আলাদা session arrange করে দিবো। Facebook বা WhatsApp এ message দিলেও হবে।

    আরও কিছু জানার আছে?

    নির্দ্বিধায় জিজ্ঞেস করো।
